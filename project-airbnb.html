How it works

  1. Microservices

    Listing (PostgreSQL), Booking (MySQL), User (MongoDB) and Session (Redis) services behind a RESTful API gateway.

  2. Platform

    Owner and guest dashboards with live listings, availability calendars and end-to-end booking. Load-tested with JMeter at 200 req/s and 5,000 concurrent users.

  3. AI travel agent

    A LangChain agent uses profile, booking history and live location (Tavily API) to build personalized itineraries in real time.

  4. Auth & performance

    JWT with refresh-token rotation, role-based access, and Redis session caching keep booking endpoints under 120 ms at peak.
