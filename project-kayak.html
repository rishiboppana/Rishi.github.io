How it works

  1. Dual-agent design

    Agent 1 parses natural-language queries into structured intents using MCP tool-calling; Agent 2 retrieves flights, hotels and cars from a multi-database backend, with Redis caching cutting repeated lookups by ~60%.

  2. Microservices

    Independent FastAPI services for Query, Search, Cache and User, each with its own store: MySQL for bookings, MongoDB for travel content, Redis for sessions and hot-path caching.

  3. Infrastructure

    Deployed on AWS EC2 with auto-scaling and an Application Load Balancer, reaching 99.9% uptime and 40% lower peak server load.

  4. Conversational refinement

    Multi-turn context tracking and reranking let users say “make it cheaper” or “only direct flights” without restating everything.
